# МОЙ ХОББИМИР

Сайт магазина натуральных камней, бусин и фурнитуры в Казани.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Данные

Товары, цены и фотографии взяты из открытого каталога VK:
[МОЙ ХОББИМИР](https://vk.com/rukodeliye_kazan) / [market](https://vk.com/market-15939030).

Адрес: Казань, ул. Маршала Чуйкова, 53.
